Lax on a Galaxy Z Flip 3

This is the live page in demo mode, at the phone's real proportions.

Getting it onto the cover screen. The Flip 3 only runs widgets there by default. Install Good Lock → MultiStar → "Launch apps from cover screen" and add Chrome. If your One UI version doesn't offer that, a cover-screen launcher app like CoverScreen OS does the same job.

Orientation. Held closed and upright, the strip is landscape, so the left/right layout applies. Hold it sideways and Lax switches to the tall 260×512 layout. Open, it uses the full fluid layout.

Always on. Lax asks the browser to keep the screen awake. For a desk buddy, keep the phone charging with Settings → Battery → Protect battery turned on (charging stops at 85%).

Same page everywhere. All three poses are one URL. The layout follows the screen size, so closing or opening the phone just changes Lax's body.
