pair with Lax

  1. Install the app: npm run android with the phone plugged in (USB debugging on).
  2. Scan this with the Flip's camera. It opens Lax; tap pair ▶. (Or npm run android -- --pair does it over USB.)
  3. Allow the mic and notifications, and let Lax ignore battery optimisation. On Samsung also add Lax to Settings → Battery → Background usage limits → Never sleeping apps.
